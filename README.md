# ⚔️ ML Quest — Zero to Interview

Геймифицированный интерактивный курс на 5 недель: Python → Classic ML → NLP/Transformers →
LLM → RAG → Agents → Production. Контент на английском, весь код пишешь и запускаешь
**прямо в браузере** (Pyodide) — IDE не нужна.

## Как запустить

**Дважды кликни `start-course.command`** — поднимется локальный сервер и откроется браузер.

Либо руками:

```bash
cd "$(dirname "$0")" && python3 -m http.server 8765
# затем открой http://localhost:8765
```

Первый запуск Python-тренажёра качает Pyodide (~10-20 сек), дальше всё кэшируется.
Нужен интернет (CDN: Pyodide + CodeMirror). Прогресс хранится в localStorage браузера —
в ⚙️ Settings есть экспорт/импорт бэкапа.

## Что внутри

- **Map** — 5 недель × 6 дней. День = урок → квиз → 2-3 кодовых задачи → флешкарты.
  Шестой день недели: домашка + **босс-экзамен** (T1–T6 из роадмапа, с таймером).
- **Trainer** — редактор кода с тестами, подсказками и эталонным решением
  (подглядел до решения — половина XP). Run/Submit, автосохранение.
- **Cards** — интервальные повторения вопросов с собесов. Отдельные колоды
  OPT (обучение/PEFT), INF (инференс/сервинг), QTZ (квантизация), PRD (продакшн).
- **Bank** — все вопросы с модельными ответами, поиск.
- **Playground** — песочница с numpy/pandas.
- Геймификация: XP, уровни, 🔥 стрик (с заморозками), бейджи, дневной квест,
  конфетти по делу.

## Структура проекта

```
index.html, js/, assets/   — приложение (vanilla JS, без сборки)
data/week1..5.js           — контент недель (уроки/квизы/задачи/боссы)
data/cards.js              — банк интервью-вопросов
docs/content-spec.md       — контракт формата контента (как добавлять своё)
docs/DESIGN.md             — дизайн-документ
tools/                     — валидатор контента и прогон эталонных решений
```

## Проверка контента (если редактируешь data/*)

```bash
node tools/validate.js
node tools/extract.js data/week1.js /tmp/w1.json && ./.venv/bin/python tools/check_solutions.py /tmp/w1.json
```

Плюс в приложении: ⚙️ Settings → content QA — прогоняет все эталонные решения
в настоящем браузерном рантайме.

## Ограничения

- threading/multiprocessing в браузере не выполняются — эта тема даётся теорией и
  квизами; asyncio работает по-настоящему.
- sklearn/torch в тренажёре не запускаются — всё реализуется с нуля на numpy
  (для собесов это плюс, а FastAPI-домашка недели 3 имеет отдельный «IDE track»).
